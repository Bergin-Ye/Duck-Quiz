# Duck Path Learning — 开发路线图

| 维度 | 状态 |
|------|------|

## 一、核心功能（必须完成才能上线）

### 1. 题库系统
- **现状**: 硬编码 5 道题，所有路径共用
- **需要开发**:
  - 设计题库数据结构（按路径 > 节点 > 题目分层）
  - 每个节点 20-30 道题，9 条路径 × 5-6 节点 ≈ 975 道题
  - 根据 `nodeId` 和 `pathId` 加载对应题目
  - 题目随机排序，避免重复
  - 支持单选题（当前）+ 未来扩展多选/填空
- **涉及页面**: `quiz.vue`
- **新增页面**: 无（数据层改造）

### 2. 数据持久化
- **现状**: 仅存储路径选择，答题结果不保存
- **需要开发**:
  - 答题结果存储（correct/total/timeSpent/timestamp）
  - 玉米币余额读写（答题奖励 + 每日签到）
  - 错题记录写入（答错的题目自动加入错题本）
  - 节点进度更新（完成 → 解锁下一个）
  - 连续天数计算（每日登录打卡）
- **涉及页面**: quiz.vue → quiz-result.vue → index.vue → notebook.vue → statistics.vue
- **存储方案**: `uni.setStorageSync` / `uni.getStorageSync`（本地先行，后续接 API）

### 3. 错题本动态化
- **现状**: 硬编码 3 组 9 条错题
- **需要开发**:
  - 从存储/API 加载用户真实错题
  - 按学科/节点分组
  - 错题计数（答错次数）
  - "重做"按钮跳转到对应题目
  - 支持删除已掌握的错题
  - 搜索功能（按标题/描述关键词过滤）
- **涉及页面**: `notebook.vue`
- **新增功能**: 搜索框 + 过滤逻辑

### 4. 统计数据动态化
- **现状**: 所有数据硬编码在模板和 data()
- **需要开发**:
  - 题目数：累计答题总数
  - 准确率：正确数 / 总数
  - 连续天数：每日登录打卡记录
  - 总玉米币：从存储读取
  - 每周学习：按天统计答题分钟数
  - 掌握进度：按节点统计完成百分比
  - 日期范围切换（本周/本月/全部）
- **涉及页面**: `statistics.vue`
- **新增功能**: 日期选择器弹窗

### 5. 个人资料动态化
- **现状**: 用户名/等级/玉米/加入日期硬编码
- **需要开发**:
  - 从存储/API 读取用户信息
  - 等级计算（基于总答题数或经验值）
  - 玉米币实时显示
  - 成就系统解锁逻辑（快速学习者/玉米收集者/大师/探索者）
- **涉及页面**: `profile.vue`

### 6. 路径进度系统
- **现状**: 节点状态不更新，永远停在第一个
- **需要开发**:
  - 答题完成后标记节点为 `completed`
  - 自动解锁下一个节点为 `current`
  - 已完成节点支持"再次挑战"
  - 进度持久化（按路径存储）
- **涉及页面**: `index.vue` + `quiz-result.vue`

## 二、设置页面（需要新建）

### 7. 订阅页面 `pages/subscribe/subscribe`
- 功能：展示订阅方案（月/年）、价格、特权说明
- 接入：Apple In-App Purchase（需 StoreKit 集成）

### 8. 备份页面 `pages/backup/backup`
- 功能：导出学习数据为 JSON、导入恢复
- 本地方案：`uni.saveFile` + 分享
- 云端方案：绑定账号后同步到服务器

### 9. 账户页面 `pages/account/account`
- 功能：登录/注册、头像修改、昵称修改、注销账号
- 方案：手机号 + 验证码 或 第三方登录（微信/Apple）

### 10. 心情页面 `pages/mood/mood`
- 功能：每日学习心情记录（emoji 选择）、心情统计图表
- 设计：轻量级，选择 emoji + 可选备注

### 11. 通知设置 `pages/notification/notification`
- 功能：每日学习提醒开关、提醒时间设置、连续天数提醒
- 接口：`uni.requestSubscribeMessage` / 本地推送

### 12. 每周开始设置
- 功能：选择每周起始日（周一/周日）
- 实现：简单选择器弹窗，存储到本地

## 六、技术架构建议

```
当前（本地 Demo）:
  pages/ → UI 组件
  data() → 硬编码数据
  uni.storage → 路径选择

目标（可上线）:
  pages/ → UI 组件
  store/ → 状态管理（Vuex/Pinia）
  api/ → 接口封装
  utils/
    storage.js → uni.storage 封装
    question-bank.js → 题库加载/随机
    stats.js → 统计计算
  static/
    questions/ → 本地题库 JSON（离线优先）
```

离线优先策略：题库以 JSON 打包到本地，用户数据存 uni.storage，后续可选接入云端同步。
