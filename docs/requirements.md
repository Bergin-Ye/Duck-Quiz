# Duck Path Learning - 产品需求文档

## 核心原则

- **所有数据必须是动态的**，不能有硬编码的假数据
- 用户答题、学习行为都会实时改变数据
- 所有页面可交互切换，导航完整

---

## 页面需求

### 1. 首页 - 今日旅程 (Journey Map)

- 显示当前学习路径的节点图
- 已完成节点可**再次挑战**（点击进入测验）
- 当前节点可点击进入测验
- 锁定节点显示提示"请先完成前置课程"
- 鸭子图片每日随机更换（8张轮换）
- 玉米余额实时显示
- "切换路径"按钮可切换不同学习路径

### 2. 测验页 (Quiz)

- 题目从题库中加载（非硬编码）
- 选择选项后显示反馈：
  - **答对**：显示"正确！" + 玉米币弹跳动效（短暂弹出后消失）
  - **答错**：显示"错误！"+ 正确答案 + **解析**（解释为什么）
- "下一题"按钮紧跟反馈区域下方（不用滚到底部）
- 不显示持续的 "+10 corn" 文字，改为短暂动画
- 最后一题完成后跳转结果页

### 3. 测验结果页 (Quiz Result)

- 显示正确率、获得玉米、用时、连续答对数
- "再试一次"重新开始该章节测验
- "复习错题"跳转错题本
- "返回首页"跳转首页

### 4. 错题本 (Notebook)

- 按学科/章节分组
- 分组卡片可**展开/收缩**（已有交互）
- 每道错题显示：题目、错误次数、重做按钮
- 重做按钮跳转到对应测验

### 5. 学习统计 (Statistics)

- 显示题目数、准确率、连续天数、总玉米币
- 每周学习柱状图
- 各主题掌握进度条

### 6. 个人资料 (Profile)

- 用户信息展示
- 成就徽章
- 设置项

---

## 数据流

```
用户答题 → 更新错题本 → 更新统计 → 更新玉米余额 → 更新首页状态
```

- 答对：玉米+10~15（随机），连续+1
- 答错：记录到错题本，连续归零
- 完成章节：解锁下一节点

---

## 交互细节

### 测验反馈动效

- 玉米币：从数字位置弹出，向上飘动后淡出（约0.8秒）
- 答对：绿色背景闪烁
- 答错：红色背景 + 显示解析区域

### 错题本展开

- 点击分组头部 → 展开/收缩错题列表
- 展开时显示错题卡片，包含"重做"按钮
- 收缩时只显示分组名和错误数量
